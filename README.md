# ACTIVIDAD 4: Taller: ejercicios prácticos en Phyton

En este repositorio encontrará el desarrollo correspondiente a la Actividad 4 de la asignatura Lenguaje de Programación II.

## Ejecución 

Para ejecutar cada uno de los ejercicios asignados, se debe utilizar el siguiente comando:

```bash
python main.py
```

En el archivo `main.py` se encuentran los cuatro ejercicios, cada uno implementado dentro de una función diferente.

## Aclaración sobre el uso de IA (Disclaimer)

La Inteligencia Artificial fue utilizada como herramienta de asistencia tecnológica, específicamente para realizar correcciones de estilo en la documentación y para la generación de datos de prueba aplicados en los casos de testeo.
